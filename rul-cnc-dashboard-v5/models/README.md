# Models folder

This folder holds the CNN-LSTM files from the Colab export (outputs/models/), used by page 2:

- preprocessing.json  (required; records sklearn 1.6.1 and TensorFlow 2.21.0)
- cnn_lstm_seed42.keras, cnn_lstm_seed43.keras, cnn_lstm_seed44.keras  (required)

Other models (LSTM, tabular) are not needed by the dashboard.
